# Neon Barrage database

`migrations/20260805000000_create_leaderboard.sql` is the reproducible schema for the public leaderboard. It creates one table with a UUID primary key, server-generated timestamps, database-side name/score checks, RLS, and a deterministic top-score index.

The Supabase `anon` role can select rows and insert only `player_name` and `score`. The insert policy repeats the validation checks, while the table constraints enforce them for every writer. `id` and `created_at` are generated by PostgreSQL, and there are no public update or delete grants or policies.

Apply it to a fresh project with the Supabase dashboard SQL editor, the Supabase Management API migration endpoint, or the Supabase CLI after linking the project. The browser uses only the project URL and publishable/anon key; no database password or service-role key belongs in the frontend.

After applying it, run the read-only catalog checks with `psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f supabase/verify.sql`.
